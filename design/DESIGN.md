## 버전
- bootstrap 5.3
- 아이콘: Bootstrap Icons (CDN 한 줄, `.claude/rules/templates.md` 4번)

## 참고한 화면
- 인스타그램 웹, **라이트 모드**로 옮긴다 (레퍼런스는 다크 모드 캡처)
- `ref/ref1.png` — 피드 (게시물 카드)
- `ref/ref2.png` — 프로필 윗부분
- `ref/ref3.png` — 프로필 사진 격자 · 마우스 올렸을 때

## 색
- 바탕: 흰색 `#ffffff` 하나만 쓴다
- 글자: 검정 `#000000`
- 보조 글자(시간 · "더 보기" · "댓글 N개 모두 보기"): 회색 `#737373`
- 구분선 · 입력 칸 테두리: 연회색 `#dbdbdb`
- 회색 버튼(프로필 편집 등): 바탕 `#efefef`, 글자 검정
- 강조(로그인 · 가입 · 게시 버튼, 댓글 "게시" 글자): 파랑 `#0095f6`
- 좋아요 누른 하트만 빨강 `#ff3040`

## 글자
- 시스템 글꼴 (Bootstrap 기본, 따로 불러오지 않는다)
- 본문 14px
- 이름: 굵게(600)
- 시간 · 보조 글자: 본문보다 작게, 회색
- 프로필 이름: 크게(20px 정도)

## 간격
- 피드: 가운데 한 줄, 최대 폭 470px
- 프로필 · 상세: 최대 폭 935px (ref2 인스타 웹 프로필 폭)
- 폼 상자(새 글 · 수정 · 로그인 · 가입): 최대 폭 400px
- 게시물과 게시물 사이: 연한 구분선 + 위아래 여백
- 카드 안 줄 사이: 촘촘하게 (머리 → 사진 → 아이콘 줄 → 본문 → 댓글 링크)

## 프로필 사진 (동그라미)
- 사진이 있으면(`avatar_url`) 동그랗게 잘라 보인다
- 없으면 기본 프로필: 연회색 동그라미 + 사람 모양 아이콘
- 쓰는 곳: 왼쪽 메뉴의 내 프로필 · 피드 머리 · 프로필 페이지 위쪽 (크기만 다름)

## 게시물 카드
- `ref/ref1.png`처럼. 테두리 · 상자 없음
- 순서
  1. 머리: 동그란 프로필 사진 · 이름(굵게) · `•` · 올린 시각(회색). 사진과 이름 둘 다 글쓴이 프로필 링크
  2. 사진 (아래 「사진」)
  3. 아이콘 줄: ♡ 좋아요 수 · 💬 댓글 수
  4. 본문: `이름(굵게) 본문`
  5. `댓글 N개 모두 보기` (회색, 상세 링크)

## 사진
- 피드 사진: 4:5로 자른다 (가운데 기준으로 채움), 모서리 살짝 둥글게
- 사진 없는 옛 글: 사진 칸을 그리지 않는다

## 프로필
- `ref/ref2.png` + `ref/ref3.png`
- 위: 왼쪽 큰 동그란 프로필 사진, 오른쪽 이름(크게) · 게시물 수
- 버튼: 회색 바탕 둥근 버튼
- 위 숫자: 게시물 · 팔로워 · 팔로잉 수
- 내 프로필이면 프로필 사진 동그라미를 누른다 → 가운데에 "프로필 사진 바꾸기" 창(Bootstrap 모달)이 뜬다
  - 사진 없을 때: 파일 고르기 + 파란 "사진 올리기"
  - 사진 있을 때: "현재 사진 삭제"
  - 맨 아래 "취소"
- 남의 프로필이면 팔로우 버튼(팔로우 = 파랑, 팔로잉 = 회색)
- 아래: 3열 사진 격자, 칸 사이 아주 좁은 틈. 칸 비율은 ref3처럼 세로로 긴 3:4
- 칸에 마우스를 올리면 어둡게 덮이고 가운데에 ♥ 좋아요 수 · 💬 댓글 수 (흰 글자)

## 상세
- 인스타 웹 상세처럼: 왼쪽 큰 사진(4:5) · 오른쪽 칸(머리 → 본문 · 댓글 목록 → 좋아요 수 · 시각 → 댓글 입력)
- 화면이 좁거나 사진 없는 글이면 위아래 한 줄
- 내 글이면 머리 오른쪽 `···` 버튼 → 프로필 사진 창과 같은 모양의 창(수정 / 삭제 / 취소)
- 좋아요는 수만 보인다 (상세는 내가 눌렀는지 정보를 받지 않음)

## 댓글
- 한 줄에 `동그란 프로필 사진 · 이름(굵게) 내용`, 그 아래 회색 작은 글자로 시각 · (내 댓글이면) 삭제
- 입력: 테두리 없는 칸 + 오른쪽에 파란 글자 "게시"

## 폼
- 로그인 · 가입 · 새 글 · 수정: 가운데 좁은 상자, 연회색 테두리 입력 칸, 파란 꽉 찬 버튼
- 새 글: 상자 제목 "새 게시물 만들기", 칸 순서 사진 → 내용, 버튼 "공유하기"
- 수정: 상자 제목 "정보 수정", 사진(바꿀 수 없음, 보여 주기만) → 내용, 버튼 "완료" · 회색 글자 "취소"
- 로그인 · 가입: 상자 맨 위 insta 글자 로고(점이 빨간 i), 칸은 안내 글자(placeholder)로, 파란 꽉 찬 버튼. 상자 아래에 작은 상자 하나 더 — "계정이 없으신가요? 가입하기" / "계정이 있으신가요? 로그인"
- 오류 문구(로그인 실패 · 중복 아이디): 상자 안 버튼 아래, 느낌표 아이콘 + 검정 글자 (빨강은 좋아요에만 쓴다)

## 배치
- 왼쪽 세로 메뉴 (화면 왼쪽에 붙어 있음)
  - 맨 위: 새로 만든 insta 로고 (base.html 꾸밀 때 시안을 보여 주고 정한다)
  - 순서: 로고 → 홈(`/posts`) → 새 글(＋) → 내 프로필(내 프로필 사진, ref1 왼쪽 메뉴의 동그란 사진 자리) → 맨 아래 로그아웃
  - 로그인 안 했을 때: 로고 → 홈 → 가입 → 로그인
  - 평소에는 아이콘만, 마우스를 올리면 글자(메뉴 이름)가 나온다. 내 프로필에 올리면 내 이름
  - 화면이 좁으면 아래쪽 가로 막대로 바뀐다
- 나머지 내용은 메뉴 오른쪽 공간의 가운데

## 쓰지 않는 것
- 그림자 · 그라데이션
- 앱에 없는 기능의 가짜 버튼 (스토리 · 메시지 · 릴스 · 북마크 · 공유 · `...` 등)
- 색 있는 배경 (바탕은 흰색만)
